# Documentación de diseño — RDFGISExplorer

Documentos que explican **por qué** el prototipo es como es (el **cómo** está
en el README raíz y en `AGENTS.md`):

- **[design-decisions.md](./design-decisions.md)** — Las decisiones de diseño
  del prototipo (vistas coordinadas, alcance exploración/análisis, panel de
  resumen, export, límites, arquitectura domain-agnostic, Native Federation),
  cada una derivada del paper DECISIONING 2026 con notas propias de
  ingeniería.
- **[dsrm.md](./dsrm.md)** — El marco metodológico: mapeo de cada componente
  del trabajo a las etapas de Design Science Research Methodology (DSRM).
